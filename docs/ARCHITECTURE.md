# 架构

## 1. 系统边界

工程把“医院经营逻辑”和“掌机平台差异”分开：

```text
Theme Hospital 原版数据
          │
          ▼
CorsixTH 0.70.1 C++ + Lua 游戏逻辑
          │
          ├── 原 SDL2 主窗口：640×480 逻辑画布
          │          └── SDL N3DS 缩放到上屏 400×240
          │
          └── th3ds Lua/C++ 桥
                     ├── 下屏管理 UI 320×240
                     ├── 3DS 输入映射
                     ├── 生命周期和原子存档
                     └── 电池/音量/Wi‑Fi/内存遥测
```

上游医院规则、AI、寻路、房间、员工、病人、战役和存档格式继续由 CorsixTH 维护。移植层处理分辨率、输入、双屏、资源位置和掌机生命周期。

## 2. 上屏

CorsixTH 内部仍保持 640×480。`tools/patch_sdl2_n3ds.py` 修改 SDL2 N3DS 软件帧缓冲：

- 计算保持宽高比的目标区域；
- 使用确定性最近邻缩放；
- 把 640×480 映射到 320×240；
- 在 400×240 上屏左右各留 40 像素；
- 触摸下屏保持原生 320×240，无缩放。

保留 640×480 逻辑坐标可以最大限度减少 CorsixTH UI、鼠标事件和 Lua 窗口体系的改动。

## 3. 下屏

`BottomUiController` 管理六个页签：

1. Dashboard：资金、声誉、日期、排队、关键入口。
2. Build：房间、走廊物品、编辑房间、雇员。
3. Staff：员工列表入口和所选员工信息。
4. Patients：病人和医院状态入口。
5. Finance：银行、图表、政策。
6. Messages：顾问消息和待处理通知。

底部固定四个动作：暂停、速度、总览、返回。触摸命中区由 `ScreenLayout` 统一定义，渲染和输入共享同一几何源，避免“看得到但点不到”。

## 4. 输入

| 硬件 | 世界/菜单 | 建造/放置 |
|---|---|---|
| 圆形摇杆 | 连续移动镜头；菜单中移动焦点 | 连续移动视角 |
| 十字键 | 16 像素精确移动或菜单导航，带重复 | 精确移动光标/物品 |
| A | 确认、左键 | 放置 |
| B | 取消、Escape | 取消 |
| X | 快捷菜单 | 旋转/右键 |
| Y | 双击详情 | 墙体透明切换 |
| L/R | 缩小/放大 | 上/下一个分类 |
| Start | 暂停/继续 | 暂停/继续 |
| Select | 城镇总览 | 城镇总览 |
| 触摸 | 页签、列表、动作 | 拖出房间、选择工具 |

触摸识别包括按下、移动、抬起、单击、双击和长按；移动容差和时间阈值集中在 `InputMapperConfig`。

## 5. Lua 桥

C++ 预加载 `th3ds`、`lfs` 和 `lpeg`。`lua/3ds/platform.lua` 在 `TheApp` 创建后挂载，完成：

- 隐藏原 640 像素底栏；
- 周期同步资金、声誉、日期、员工、病人、队列和消息；
- 把原生动作映射到 CorsixTH 的 `World`、`GameUI`、`UIBottomPanel` 和 `UIEditRoom`；
- 包装保存函数，使用原子提交；
- 在挂起时暂停，在恢复时还原速度；
- 保持游戏的鼠标式输入语义，减少对上游窗口系统的侵入。

`config/corsixth-lua-api-v0.70.1.json` 列出所有依赖的方法。`check_upstream_lua_api.py` 采用失败关闭策略，上游方法漂移时拒绝继续集成。

## 6. 保存和生命周期

保存流程：

```text
写入 slot.sav.tmp
      │
      ├── fsync 临时文件
      ├── slot.sav → slot.sav.bak
      ├── slot.sav.tmp → slot.sav
      └── fsync 目录（平台允许时）
```

启动时恢复优先级为正式文件、临时文件、备份文件。生命周期控制器处理：周期自动保存、挂起保存、恢复、退出和关键 I/O 延迟，避免保存写到一半被退出。

## 7. 音频

首版继续使用精简 SDL_mixer：WAV 和 STB Vorbis，关闭 FLAC、MP3、MIDI、Opus、MOD、GME 和 WavPack。公共音频模块提供：

- 单声道到立体声的恒功率声像；
- 饱和混音；
- 固定容量立体声环形缓冲；
- 单元测试覆盖溢出、环回和边界。

## 8. 资源和 SD 卡

`tools/th3ds_pack.py` 验证原版目录并复制到：

```text
sdmc:/3ds/corsixth/game/
```

CorsixTH Lua、关卡和开放资源位于：

```text
sdmc:/3ds/corsixth/
```

分发目录包含 SHA-256 清单，方便检测复制损坏。
