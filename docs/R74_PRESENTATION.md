# R74 启动与暂停呈现

此批只调整启动图投影、固定文字和暂停提示。游戏画布、鼠标/触控映射、清晰/广角视窗、World 时间和操作权限保持原合同。

## 画面拥有者

`BootPresentation` 单独拥有 `BootText → BootArtwork → Game`；无光盘路径可直接进入 Game。Error 锁存后拒绝后续正常绘制，shutdown 显式复位。阶段码继续记录诊断，不参与显示状态判断。

- 下屏早期页面使用居中三行：`载入中，请稍等……`、`移植适配：uncodeuncle.com`、`Based on CorsixTH`。既有 SDL/GPU 视频初始化顺序保持。正常加载页隐藏工程数值，boot.log 和错误页保留。
- App 在第一次 Load01V 绘制之前通知 BootArtwork，在任何 UI、intro、主菜单绘制之前通知 Game。原有第二帧 FreeType 版权声明保留。
- 原图 640×480，光盘实际包围框 `(163,84)–(474,395)`。仅去掉黑边，取 `(144,64,352,352)` 统一以 10/11 缩到 320×320；上半片放上屏 `(40,80,320,160)`，下半片放下屏 `(0,0,320,160)`，光盘直径约 283px。原图底部 `(0,432,640,48)` 的版权条另以 1/2 等比放下屏 `(0,184,320,24)`；光盘与署名均完整保留。无白框、无普通覆盖条。GPU 在单个 job 内提交两个 LCD，CPU fallback 复用现有 surface。正常游戏仍由原 GameView 绘制。
- GPU 继续按像素中心采样，CPU 延用原 top-left 最近邻；浮点边界可以选中相邻源像素。两种已有采样约定单独用像素 oracle 验证，未声称每个细小字形像素相同。改装屏物理尺寸、铰链间隙及实物可读性待真机确认。

## 暂停

最终 World 源文件的 `updateScreenBlueFilter` 在 3DS 保持滤镜关闭；桌面原行为保留。World 的 `isCurrentSpeed("Pause")`、`mustPause()` 和 `user_actions_allowed` 产生只读底屏状态，UI 不拥有第二份暂停开关。

普通暂停在已有 13 像素条带中显示 `已暂停 · Start继续`；已允许暂停操作时显示 `已暂停 · 可建造 · Start继续`。强制暂停窗口不显示误导的 Start 提示。错误通知优先，普通控件提示让位于暂停状态。固定条带内容变化时才重新栅格化，复用原 SoftwareCanvas 与 GPU overlay。

## 固定文字资产的成功路径

`tools/generate_presentation_masks.py --font FONT --output include/cth3ds/presentation_masks.hpp`

- 来源：项目原已使用的完整 `HarmonyOS_Sans_SC_Medium.ttf`，SHA-256 `6ed1553edccddc48eb27ff25d134a4a715cf54211238d4840b3038576cba1944`。
- 本次主机：Pillow 12.2.0、FreeType 2.14.3，BASIC 布局；输出头记录版本及字体 SHA。生成器验证每个字符存在，缺字立即失败。既有 SD 子集缺少“稍”和间隔点，因此直接从同一完整字体生成这些固定词句；SD 字体不扩充。
- 五张 4-bit alpha mask 总共 **4,976 B** 只读像素数据，字体对象和栅格化工具全部留在电脑端；未加入完整字体、纹理或线性内存池。源码保留字体来源，不包含源字体文件。原游戏图、原有许可和署名没有重绘或删除。
- 分辨率：加载主句 162×19，署名 171×14，Based 119×10，普通暂停 103×13，可建造暂停 150×13。载入页与条带使用同一小型 mask 绘制器，精确保留英文大小写。
