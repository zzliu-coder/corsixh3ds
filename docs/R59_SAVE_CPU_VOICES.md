# R59：保存临时内存、CPU 热点与常用语音

本轮基于 R58 `50be1a2d53aa909dc35e7fb70fe5a33d991d9eb5`。
固定上游继续使用 `56bd5d00f76331c7f76d7b696726a7926303ca0c`；
用户提供的 Windows 中文版仅用作私有声音输入，不运行其中程序，不采用其 Lua/引擎代码。

## 当前证据与施工边界

R58 真机约 17 分钟，GPU 路径已启用。自动三组同档样本约 11.6/11.4/11.4 FPS，
正常模拟吞吐约目标 62%；30 FPS 目标尚未达到。中文与音乐的样本差异较小，不能推出零成本。
Slot2 曾保存成功；后续自动保存、Slot2 和退出保存出现 `persist.dump: not enough memory`。
两次保存前的普通堆估算余量接近；日志没有记录失败分配的大小，无法确定唯一内存根因。
旧 Slot2、备份、Slot3、退出档、日志和基准输入全部保留。

## 私有资源转换与运行边界

素材保留在用户私有目录；Git 只包含转换代码和合成测试。

- 中文源为用户提供的 `SOUND-0.DAT`。与现有英文相比，747槽位一致，147个语音条目有变化。
- 外语源1–5按固定上游语言映射识别；其中一些普通音效命名有差异。
  输出以英文的事件编号/通用音效为共同基线，只按同名事件替换这147个语音条目，避免换语音影响游戏音效。
- 电脑端使用 SDL2 转换为 PCM S16LE、22050Hz，保留原单/双声道。
  已符合规格的 PCM 样本不重采样；逐条复查帧数、时长、名称、索引与摘要。
- 七套 DAT 分别放 `Voices/`。运行时只持有当前音源的索引与有上限的活跃音效缓存，
  所有音源均不整包读入 Lua；未转换的外语音源包不显示为可切换选项。
- 音乐复用已转换的8首单声道PCM16/22050 WAV；播放时只持有一个文件解码器。
  存储体积让位于读取、解码和运行成本。新增文件首次传输一次，后续按摘要复用。
- 含中文语音的新安装包默认 `speech_language="zh"`。已有设备配置在双次备份后仅调整明确字段；
  用户之后可在音频设置中切换，选择会保存，界面仍沿用原语言设置。

接口文档：[SDL2 BuildAudioCVT](https://wiki.libsdl.org/SDL2/SDL_BuildAudioCVT)、
[SDL2 ConvertAudio](https://wiki.libsdl.org/SDL2/SDL_ConvertAudio)、
[Lua分配器约定](https://www.lua.org/manual/5.4/manual.html#lua_Alloc)。
