## 本轮实现

| 项目 | 实现及边界 |
|---|---|
| 覆盖存档 | 奇数宽确认窗口中心转为有限、有界的整数像素，再传严格 Lua/C++ 接口；确认/取消与鼠标坐标保持 |
| GPU 真实绘图 | 图像、字体、填充、线段、裁剪通过实际 renderer；透明、调色、翻转保持 painter 顺序；上下屏由同一 GPU 画布输出 |
| 有界资源 | 3 张 512² RGBA8 线性图集共 3 MiB；画布 VRAM 2 MiB；双屏 VRAM 691200 字节，无深度缓冲；4096 图元缓冲、256 KiB 命令缓冲及 32 KiB 提示纹理另计 |
| 安全换页 | 已提交队列完成后才能覆盖图集页；CPU 源图保留用于重新上传，和原精灵统一预算；GPU 路径关闭重复翻转副本 |
| CPU 热点 | 温度按地图持有相邻权重缓存与连续快照；墙/房间/暖气状态变动自动失效；保留原整数结果与地图边缘规则 |
| 调度 | 输入持续采样，18ms 原模拟节拍与呈现独立；呈现最高 60Hz，静止菜单最多 100ms 刷新一次，输入/变化仍可及时重绘；有界追赶和欠账继续记账 |
| 观测 | 实际 World/UI 分段、温度/寻路/输入计时、GPU 完成队列耗时/等待/图集/命令峰值、普通堆/linear/VRAM；资源解码观察不再重置模拟时钟 |
| 自动基准 | 单次启动读取专用存档副本，Normal 和最高普通档各预热 30 秒、采样 60 秒，最后重新读入原始副本供用户操作 |

GPU 初始化失败会清理自己分配的对象，并记录原因后使用软件参考路径。
应用根目录 `gpu-software.txt` 可在下次启动强制参考路径；它与正常候选共享资源和存档。
应用不会重设 SDL 分配的 LCD 格式，输出转换跟随实际屏幕缓冲格式。

## 自动基准的保护与可解释性

- 安装器把已读回且校验过的医院复制为 `Benchmark/input.sav`；原 `Saves/` 不覆盖。
- 测试期间所有自动/恢复保存转到 `Benchmark/Saves/`，周期自动保存暂时关闭；结束、取消、失败恢复原目录与设置。
- `benchmark-run.txt` 内容须精确为 `R52` 加换行；启动消费为已运行标记。崩溃或下次启动不会再次自动运行。
- B 取消；HOME、合盖或退出结束样本。遇到强制暂停窗口或速度被游戏改变时记录失败，保持上游规则，不能把暂停样本算通过。
- `benchmark` 标记实际速度、时间、日期；`frame-timing` / `simulation-budget` / `cpu-work` / `gpu-work` 等日志共同判断。
- 主机 GPU 延迟队列模型验证所有权、顺序、翻转、裁剪、透明、分片、换页和缓冲上界；它不模拟 PICA 时序，斜线栅格、LCD 旋转、纹理一致性与实际画面仍须设备观察。

## 真机最短操作

1. 进入 Homebrew Launcher，打开 `/3ds/corsixth/CorsixTH-3DS.3dsx`。
2. 若已安装单次基准，自动载入副本，等约 3 分钟加三次载入时间；需要中止按 B。
3. 出现 `BENCHMARK DONE - YOU CAN PLAY` 后，检查人物、墙体遮挡、菜单、音效，摇杆滚图、触控拖动和 L 切换。
4. R+Start 打开保存：覆盖 Slot3 → 确认，随后退出重开加载，核对房间/人员/进度。旧槽位在电脑有校验备份。
5. 有余力再做一次合盖、HOME 返回。退出游戏后开 ftpd，让电脑读回结果。

30 FPS+ 是目标；呈现间隔不能替代人物/经营实际推进。Normal 无持续模拟欠账、
输入无溢出、稳定堆余量至少 8 MiB（操作至少 4 MiB）、linear/VRAM 不持续损失也须一并验证。
最高普通档为上游 `And then some more`，排在 `Max speed` 之后，顺序保持。

后续按本轮真实热点选择图集布局/上传、World/UI、寻路或资源预处理；复用构建与工具链缓存，
保持差量上传。中文/音乐接入、大关容量、长时间稳定性沿原计划继续，逐项标明尚未通过。
