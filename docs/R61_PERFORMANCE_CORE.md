## 内存与兼容性边界

- 图像格式、像素精度、图集页数、音频格式和缓存总上限保持。新增严格帧分布约 8.5KiB，
  属静态观察存储；重置就地执行，避免 R56 那类大型栈临时对象。
- 普通堆余量仍为估算。音效 admission 不构成内存预留；实际分配继续检查失败。
  压力回收检查间隔 0.5 秒、完整回收最短间隔 2 秒；真机需要检查触发次数及停顿收益。
- 瞬时压力下可以漏掉一条新音效；日志 `sound_play/pressure-skip` 必须保留，
  这类记录不能算“声音完整性通过”。已在播放的声音和用户进度不受主动淘汰。
- 旧档解码后对索引就地 compact。旧档最初解码时的密集对象峰值仍存在，
  本批不声称已经降低全部旧档载入峰值。
- 原生存档编码保持兼容。新档对象图采用稀疏索引，回退 R60 时应恢复原来保留的 R60 存档。
  R61 新档交给 R60 继续写入未获证明；部署不得覆盖唯一旧档副本。
- 正常保存的完整 GC 从外围前后各一次加内部两次，收敛为内部两次加外围后一次。
  内部弱引用回收/终结器顺序保留；load 外围前后回收保持。

## 同一份真机候选集中验收

1. 保留 R60 二进制、部署身份和当前存档；使用固定医院副本作为
   `Benchmark/input.sav`，每轮只改候选文件。
2. 一次性标记 `benchmark-run.txt` 内容为 `R61\n`。正常媒体配置下自动进行
   英文无音乐、中文无音乐、中文有音乐三组同档 Normal 采样。
   不按键、不触摸、不动摇杆；任何输入或强制暂停都会中止并标明原因。
3. 采样结束后只集中验证：购买地块/扩建、开高频窗口、中文语音与音乐、
   同槽连续保存两次、保存并退出、重开确认员工/房间/进度恢复。
4. 读回一次日志和存档，分别判断稳定帧率、模拟推进、最长停顿、保存阶段、
   GC 频率、图集上传与内存低水位。主机 PASS 与上传读回 PASS 均不能替代这些结果。
