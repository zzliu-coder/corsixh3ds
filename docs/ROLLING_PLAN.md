## 基准与判据

同候选/语言/资源/存档/速度：菜单、已保留小医院、后期空关与繁忙存档，
预热30秒、采样60秒、尽量重复3次。冷启动、进关、保存、读档单列。
记录完整帧间隔/P95/最长停顿，逻辑/绘制/双屏、游戏日期推进、输入队列延迟和溢出。
同一个Slot1分别测试Normal、Max speed、And then some more，标注目标倍率1/1.5/3。
上述倍率仅用于比较上游参数；快捷键与触摸菜单一致，保留上游五档Slowest、Slower、
Normal、Max speed、And then some more，不新增掌机速度参数或游戏时间规则。
`simulation-clock`是实际收到的计时事件和执行的App回调；两者差值反映合并，
用`workload`日期验证真实模拟推进。24倍临时Speed Up暂不绑定掌机快捷键。
目标30FPS；中间改善明确报告实际数值，不以组件通过宣称目标达成。
普通堆稳定余量8MiB、操作期4MiB作为现有最低门槛；余量不足先限制增量/定位真实持有。
线性内存单列；Lua是普通堆子集。短时采样与一关通过不能担保所有关卡。
